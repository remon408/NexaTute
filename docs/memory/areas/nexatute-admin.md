## Admin push notifications (approved 24 Oct 2026)
- [stated] Admin push notifications (approved 24 Oct 2026) in the platform admin panel and the school/college (Institute) admin panel: bell with unread count on every admin page, one click opens the item; web push (browser + installable app, pywebpush; Android app via FCM as a listed exception) plus optional email/SMS/WhatsApp; levels info (in-app/daily digest), important (push), urgent (push + email + SMS, overrides quiet hours)
- [stated] Notification events: platform — approvals (money, refunds, payroll, loans, shares, prices/plans, roles/permissions, data deletion, T&C, model rollback, API caps, maintenance, ad budget, campaigns) and important changes (new price live, approve/reject results to the maker, break-glass, new-device login, exports, failed backup, incidents, load over 60%, API spend 80%, bill/EMI due); Institute — seat changes, staff roles, notices, exam-date changes, discount requests, pending guardian consent, at-risk counts, overdue bills, ticket SLA, onboarding steps
- [stated] Notification control panel: per event choose recipients by role and/or named users, channel and level; approvals default to the approver from the approval rules (CC allowed); reminder after 4 h, after 24 h to the next approver; each user sets quiet hours and digests and can mute low-priority events but never their own approvals or security alerts; Institute head admin assigns events among its own staff only; push text never shows secrets (no salaries, student names or amounts); every notification and routing change logged; changing who gets security alerts needs security-owner approval; no new servers

## Internal staff chat (approved 24 Oct 2026)
- [stated] Internal staff chat in the platform admin panel and each school/college admin panel; staff only, each institute's chat separate, platform talks to institutes only via a support channel; one-to-one with anyone in own panel (images/files virus-scanned); no free group creation — group request (name, purpose, members) approved by a role-based approver (department head/founder; institute head admin), plus auto department/class groups by role; only the group owner adds/removes members, logged
- [stated] Chat voice/video only in the platform admin panel, allowed per role from the control panel (voice only / voice+video / group calls); calls not recorded; AI call notes only if everyone agrees
- [stated] Chat push notifications via the approved notification system: one-to-one message → push; group → push on @mention (others counted on the bell, optional all-messages push per group); incoming call → ringing push; group request → approver, result → requester; compliance alert → urgent push+email+SMS, ignores quiet hours, cannot be muted; lock screen shows only the sender, not the text (preview allowed per role from the control panel); users can mute chats or set quiet hours except compliance/security alerts; no duplicate push to a device already showing the chat
- [stated] Chat compliance check on send (own-server Qwen3Guard plus rules): passwords, API keys or bank details are blocked with a warning; confidential company information (prices, salaries, contracts, investment, code), learner/guardian personal data, harassment or attempts to move data out are sent but alert the concerned admin at once (chosen per category from user roles, e.g. security owner, DPO, finance lead, HR/founder; institute head admin); a person decides, AI never punishes; staff policy states work chats are monitored
- [stated] Chat summaries: daily AI summary of every chat in an encrypted password+2FA archive, every access logged; confidential/compliance chat summaries are kept in full detail, and the super admin chooses from user roles who may see them; full messages kept e.g. 90 days and chat summaries 6 months (decided 24 Oct 2026; lawyer to confirm), legal hold possible; not end-to-end encrypted because of scanning (encrypted in transit and at rest); runs on existing Centrifugo + PostgreSQL + LiveKit + notification service, no new servers; lawyer to check PDPO 2025 monitoring notice, retention, and whether institute chat summaries stay with us or in the institute's own archive

## Classroom voice & new admin controls (approved 28 Oct 2026)

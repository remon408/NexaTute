## Roles and names (current names from 23 Oct 2026)
- [stated] Nexa Teacher (was "AI Teacher") = live teaching only, by voice, 1:1 and batch, with 3D avatar, lip-sync and Smart Whiteboard; always shown with an "AI" label (AI transparency)
- [stated] Nexa Co-Teacher (was "AI Co-teacher") teaches everything except live voice teaching through text (full text lessons, step-by-step answers, finds recorded classes with timestamps and class summaries); answers only from the learner's own data; 25 topics/day (follow-ups on one topic count as one; replaced ~100 → 40 questions/day)
- [stated] Nexa Co-Teacher voice (23 Oct 2026): voice input (speak a question, turned into text) + listen button on each answer, both in the browser; no continuous voice conversation, avatar, whiteboard step-watching or talk ratio (Nexa Teacher-only)
- [stated] Nexa Study Hall Moderator (was Study Hall "AI moderator"): short help only (hints, the wrong step, 2–3 min) using the Co-Teacher's LLM, voice in the browser (VITS, Whisper); a group question answered once; full topics handed to the Co-Teacher or Nexa Teacher; minors may ask it by voice (group chat stays text-only for minors)
- [stated] Nexa Guard = the automated safety system (bad-language filter, porn/NSFW and child-safety blocking, harmful-link blocking, report button, behaviour-change ladder); replaces the batch "AI moderator" name; human staff are "Human Controller"
- [stated] If the server is overloaded the Nexa Teacher stops but the Co-Teacher keeps running via API (verified-answer cache → Mistral → GPT-6 Luna); lost minutes are added back; busy learners see an ETA and keep their queue place; load-aware routing suggests recorded classes first (then mock tests, true/false, summaries) and starts live only if still not understood

## Shared learner record (Nexa Teacher ↔ Co-Teacher sync, 18 Oct 2026)
- [stated] One learner record both roles read and write: level and topic mastery, which explanation type works (picture, story, step-by-step), error list, last class, exit ticket, next step; the Co-Teacher teaches in the Nexa Teacher's pattern at the learner's level with the same example and notation; the Nexa Teacher starts from where the Co-Teacher left off and switches method instead of repeating one that failed; a handover note makes a 1:1 call start at the exact step
- [stated] Combined evaluation: Learning Insights from both roles (help-assisted answers weigh less); KPIs — solved independently vs by Co-Teacher vs needing Nexa Teacher, days to mastery, which method works; Co-Teacher question depth counts in the Thinking Profile; every Co-Teacher topic gets a summary in "My summaries" and the guardian report; batch topics most asked to the Co-Teacher (counts only) feed the next class's 5-min recap
- [stated] No new software or servers for sync (PostgreSQL, pgvector, Ralph LRS, Valkey, LangGraph rows updated); summaries made on the local LLM pool, API-time summaries made later locally
- [stated] Nexa Teacher remembers each student (interests, weak points, last class) and opens with it

## Batch classes (1 Nexa Teacher : 50)
- [stated] Virtual batch: 30–50 learners with the same exam date, batch rank, shared countdown, weekly top-3, monthly batch mock test; only name or nickname and rank shown; starts on its date with any size (even 1); separate Bangla-medium and English-version batches; batches formed by placement-test level
- [stated] Batches are also separated by teaching language (e.g. Bangla batch B-07, English batch EN-03); a learner who changes the teaching language moves to a batch in that language (approved 23 Oct 2026)
- [stated] Class format: 8 min teaching → 2 min poll/MCQ (4 cycles per 40 min); adaptive pace (re-explain if <60% correct, move on if >85%); always-on "Bujhlam/Bujhini" meter; random cold-call with text answers; 5 teams of 10 with team scores; raise hand
- [stated] Peer Instruction (30–70% correct → 2-min pair discussion → re-poll); anonymous question wall with upvotes (most-voted answered first); individual homework from each learner's poll mistakes
- [stated] 28 Oct 2026: in the AI 1:50 class students' microphones are off by default; a student who wants to speak taps the button / raises a hand, so the Nexa Teacher can explain naturally and ask the student follow-up questions, and the mic switches off automatically at the end of every voice turn (keeps classroom control and natural conversation)
- [stated] 28 Oct 2026: in the AI 1:1 class the student's mic is also off by default and the student taps "raise hand" to speak; how many times is set in the admin panel, default as many times as they want; if a student disturbs too much, the AI turns the mic off and gives a motivational talk so the student doesn't do it again
- [stated] 28 Oct 2026 confirmed defaults for the disturbance rule (editable in admin): 3 off-topic/noise turns within 10 minutes → mic paused 2 minutes with a gentle, age-appropriate message, typing still allowed; same rule in 1:1 and the 1:50 batch class
- [stated] Batch recordings count as each member's own class and show all questions asked in class; personal questions belong in 1:1 time
- [stated] Per-student KPIs: attendance/time (join/leave, tab focus), poll accuracy and speed, confusion taps, questions, after-class quiz, weekly improvement (BKT); weak topic → that day's personal 1:1 time set to it + recording timestamp + Co-Teacher drill; strong topic → challenge problems and "helper" badge; error type from wrong options (concept, calculation, careless)
- [stated] Teaching quality: per-class segment report (most-confused 8-min part → next class opens with a 5-min recap); lessons pre-built and verified (3.13 pipeline); A/B two explanations, keep the better; weekly human review of worst segments plus a random weekly expert sample; AI lesson rubric (correct, clear, checks understanding, right level)
- [stated] Batch rollout: BCS and SSC batches first; measure completion % and upgrade % in Free Beta; human-teacher weekly revision class (Q2 2027) inside the batch

## Learning methods
- [stated] Learning science: 3-question pre-test before each topic; 3-min retrieval warm-up (1 day, 1 week, 1 month ago); worked → faded → independent practice (Math/Science); prerequisite gap repair via the knowledge graph; auto error notebook (re-test after 3 and 7 days, removed after 2 correct in a row); chapter pre/post-test shown to learner and guardian; weekly goal (Saturday) + 2-min reflection (Friday); 80% mastery before the next topic at launch for the Personal Plan
- [stated] 1:1 methods: Nexa Teacher watches whiteboard working and stops at the first wrong step; target talk ratio ~40% learner; tracks which explanation type works per learner and uses it first; exit ticket (1 question + own 1-line summary)
- [stated] "Brain grooming" thinking layer: problem-first start; Why → How → What if ladder; learner writes 1 own question per class scored on Bloom's levels; Thinking Profile KPIs (unseen problems, question level, cross-subject transfer, confidence vs accuracy, persistence); fear removal ("not yet" instead of "wrong", easy wins first, "best mistake of the week", quiet foundation repair); argue-both-sides debates (BCS/Bangla/Social); real-life links (physics in cricket); mental math, estimation, timed puzzles; claims framed as measurable Thinking Profile gains, not "brain training"
- [stated] Other approved learning features: low-internet mode (audio only, voice + whiteboard, ~30 kbps); BCS Written + Viva mock board (3-member AI board, different voices, feedback at the end); exam-eve mode (no new topics; error notebook + formula sheet + 10 MCQs; "go to sleep"); chapter-end Boss battle unlocking the next chapter with a badge; thana/school leaderboards; 60-second topic Shorts (Motion Studio, CDN); XP for Classroom Builder posters/themes/outfits; national events (21 February language challenge, 16 December quiz, Ramadan after-Fajr streak); weekly guardian + child quiz
- [stated] Beyond the syllabus: daily 10-min reading (stories, news, science + 3 questions); monthly mini-project (plan, measure, result, 1-min Motion Studio video); home experiments with photo/video upload and AI feedback; 2-min "explain it" voice recording with feedback; weekly 15-min text-only curiosity corner; weekly guardian coaching tip; monthly 20-min life skills (money, digital safety, time management)
- [stated] Laboratory: Virtual Lab free in all plans (browser); coding/cyber sandbox labs in skill courses up to 1 hour/day (more via Daily Pass); group lab — Nexa Teacher demonstrates, everyone runs it in their browser with a predict-first poll; 1:1 lab — free variables, stops at mistakes; SSC/HSC practical exam prep (procedure, observation, calculation, notebook help, AI viva mock); lab choices count in progress and Thinking Profile; followed by a home experiment
- [stated] OMR practice is on-screen only (no printing)

## Safety and inclusion
- [stated] Wellbeing: on signs of serious distress the Nexa Teacher pauses, responds with care, informs the guardian (age-appropriate) and shows helplines (numbers entered in the admin panel)
- [stated] Nexa Guard checks: real-time filter on the live-class speech transcript; Nexa Teacher/Co-Teacher outputs checked (Qwen3Guard); teacher content checked before publishing plus a teacher code of conduct; subject-aware context rules (religion in religious studies, wars in history)
- [stated] Behaviour ladder (education, not punishment): 1st — gentle private message; 2nd — 5-min "digital manners" lesson + private guardian note; 3rd — chat/upload off 24–72 h while study continues; serious (porn, child abuse, threats) — immediate block, Human Controller alert, guardian/institution informed, reported as the law requires; respect points and clean-conduct streak restore privileges, never public shaming; teachers: institution admin informed, warning → suspension → ban with appeal
- [stated] Inclusion: dyslexia/ADHD/slow-learner settings (dyslexia font, read-aloud, shorter segments, more breaks, less time pressure, set by the guardian); girls' and rural inclusion (low-cost phones, low-internet mode, guardian-approved safe batches, Sponsor-a-Learner prioritising rural girls)
- [stated] Face detection only for presence and one account = one user, never to judge mood or attention

## MindForge (approved 23 Oct 2026; source NexaTute_MindForge_Product_Blueprint_Updated.docx; price in [[nexatute]])
- [stated] NexaTute MindForge = cognitive assessment & development module inside NexaTute, all 12 feature groups (assessment, AI Cognitive Gym, development plans, Metacognition Coach, Creative Thinking Studio, Real-World Problem Lab, parent/teacher dashboard, research & validation console, localization, child safety & privacy, institution portal, validated assessment service); for Class 4 to adults (PlayBoom children don't get it at launch)
- [stated] No IQ-style score until expert validation and norming; no "brain growth" or guaranteed-IQ claims (shown as measured thinking-skill practice gains alongside the Thinking Profile); no "weak/smart" labels ("needs more practice"); no MindForge leaderboards
- [stated] Data sync: Nexa Teacher, Nexa Co-Teacher, Study Hall Moderator, mock tests and MindForge all write to the one shared learner record — Teacher: topic mastery, poll results, explanation type that works, first wrong whiteboard step, own-question level; Co-Teacher: topics and question depth (help-assisted answers weigh less); Moderator: where stuck, hints, "Bujhini" taps, lab mistakes; mock tests: score, time per question, error type; MindForge: domain practice results, confidence vs accuracy
- [stated] Syllabus/topic mapping: each topic tagged with the thinking skills it needs (geometry → visual-spatial, word problems → verbal + numerical reasoning, BCS mental ability → logic); works both ways (stuck topic → targeted MindForge practice; strong reasoning → harder problems from Nexa Teacher); reading, labs and beyond-syllabus items mapped too
- [stated] Strengths and practice areas flagged only with enough evidence (e.g. ≥20 attempts over ≥3 days)
- [stated] Expected syllabus completion: remaining topics × the learner's own pace per topic type ÷ available study time (plan minutes, batch routine, holidays, Ramadan) → a date range vs the exam date (on track / at risk) with levers; recalculated weekly and after every mock test; first 2 weeks a rough estimate from similar learners; prediction accuracy tracked and recalibrated; shown to the learner, the guardian's weekly report, Nexa Teacher and the institution (class summary)
- [stated] Separate consent switch for sharing MindForge data with teachers (guardian decides under 18); institutions see it only with consent; never the basis for admission, grades or discipline
- [stated] No new GPU: AI explanations on the shared GPU pool at low priority (live classes protected), scoring on CPU/browser, sync on the existing PostgreSQL
- [stated] Appears in: learner MindForge tab + Thinking Profile, guardian weekly report (expected completion date), Institute Admin class summary, platform admin (module on/off, item-bank review)

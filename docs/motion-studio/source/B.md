# Appendix B. Glossary

Terms as used in this blueprint, in alphabetical order.

| Term | Meaning |
|---|---|
| 4K Escalating | A 4K output made by upscaling a 1080p Native render; Starter and above only |
| aamarPay | Bangladeshi payment gateway used for bKash, Nagad and cards, including international cards until Paddle is approved |
| Act it yourself | Performance transfer: the client speaks a line with feeling and it is converted to the character's voice; not cloning |
| AudioSeal | Open-source inaudible audio watermark added to every output that uses a cloned voice |
| BdSL corner | A Bangladesh Sign Language avatar shown in a corner of the video |
| C2PA (Content Credentials) | Open standard for signed metadata showing how a file was made; every Motion Studio export carries it |
| Character LoRA | A LoRA trained on one series character so it looks the same in every episode |
| Chromaprint | Open-source audio fingerprinting used to detect known music in uploads |
| Cinematic mode | Full AI video generation on the server (Wan 2.2), priced at 3D rates +35% |
| Closed pilot | Two-week test with 10–15 known businesses before the public Free Beta |
| Coming soon | Status of an approved feature that has not yet passed its tests; switched on from the admin panel when it passes |
| Content Plan Mismatch Guard | Check that warns when a General-plan project is clearly Islamic and offers a plan switch |
| Delivery tier | Express (+20%, priority), Normal (within 12 hours) or Slow (within 24 hours, 10% off) |
| DMCA | US Digital Millennium Copyright Act; sets the notice-and-takedown process and the designated agent |
| Digital twin | A presenter made from a short video of the client's own face, with live consent and OTP; 18+ only |
| EBU R128 | European broadcast loudness standard, −23 LUFS |
| Enhanced mode | 2.5D motion rendered mainly in the browser from server-made key images |
| Escalating tier | An output made by upscaling a lower native render (480p to 720p, 720p to 1080p) and passing a quality gate; cheaper than the native tier above it |
| FCPXML / EDL | Timeline files that let editors open the project in professional editing software |
| FLUX.1 | Image model family; FLUX.1-schnell is Apache-2.0, FLUX.1-dev needs a paid commercial licence |
| Free Beta | 30-day public free testing period from 20 December 2026, with daily limits |
| Free Trial | 7-day free package: 1 minute a day, up to 15 seconds per video, watermarked |
| Hero shot | The most important shot of a video, rendered with the larger Wan 2.2 A14B model |
| Islamic discount | 25% off per-minute rates for verified Islamic content; the package fee is not discounted |
| Kids-safe mode | Stricter filters for children's content, with YouTube "Made for kids" set automatically |
| LoRA | Low-Rank Adaptation: a small add-on trained to teach a model a style, place or character |
| LUFS | Loudness Units relative to Full Scale; YouTube target −14 LUFS |
| Mushak | Bangladesh VAT forms; Mushak invoices are issued to business clients |
| Native tier | An output rendered directly at its resolution (480p, 720p or 1080p Native) |
| Paddle | Merchant-of-record payment service for international sales, through the USA LLC, once its API is approved |
| PDQ / TMK+PDQF | Open hashing methods for matching known illegal images (PDQ) and video (TMK+PDQF) |
| Pre-production fee | ৳20 per started 2 minutes of planned length for script, storyboard, key images and preview |
| ProRes | High-quality master video format for professional editing; Professional and above |
| Quick mode | Fastest mode: 3D animation rendered in the client's browser, with server fallback at the same price |
| Qwen3Guard | Open safety model that checks text before generation |
| Region repair | Fixing one marked area of a scene instead of regenerating the whole scene; one free per video |
| SCORM | E-learning package standard so a video with quizzes can run in a company's learning system |
| SRT / VTT | Standard caption file formats |
| SSIM | Structural Similarity Index, an image-fidelity measure used in the quality gate |
| Storyboard approval | The point where the client approves scenes, length and price; the wallet is charged and rendering starts |
| Two-person approval | Rule that every change to a user-visible value needs a second approver and is logged |
| VMAF | Video Multimethod Assessment Fusion, a perceptual video-quality score used in the quality gate |
| Voice Clone Studio | Guided in-app voice-cloning setup with live consent, base reading and emotion cards |
| Wallet | Non-cash-out, non-transferable prepaid credit used to pay for videos |
| Wan 2.2 | Open video-generation model (Apache-2.0) used for Cinematic mode |

# 6. Packages and Feature Access

## 6.1 Package principles

Remon Motion Studio is sold as monthly packages. Each package is one subscription that covers all three kinds of video in any mix: 3D Animation Video (Quick and Enhanced render modes), Cinematic Video and Islamic Content. Only the per-minute rate changes with the render mode; the monthly fee does not.

Packages have no included minute quota. The monthly fee pays for access and features; every generated minute is billed at the package's per-minute rate for the chosen output tier, and each project that uses AI pre-production carries the pre-production fee. Pricing is therefore always: package fee + pre-production fee + per-minute video rate (chapter 7).

Packages differ in four ways: the output tiers they can use, the maximum length of one video, the included storage, and the features switched on. Features are included in the package fee; there is no extra charge for using a feature, only for the video minutes it produces.

> Every package value in this chapter (fees, tiers, lengths, storage, feature cells and limits) is a launch default held in the admin panel. A change needs two-person approval, is logged and takes effect without a code change.

Notes to the table:

| White-label portal | Agency only; separate licence fee (amount to confirm) |

The Free Trial and Free Beta can create characters and voice clones only within the lifetime free allowance. Before any paid creation the app shows the count used, the one-time charge and the lifetime terms, and asks for explicit confirmation; the entitlement is recorded once so that a retry never charges twice.

## 6.5 Admin "Packages & features" page

The whole matrix in 6.4, together with the package limits in 6.2, lives on one admin page called "Packages & features" (approved 30 October 2026). It works as follows:

- Every cell (feature × package) has an on/off switch and, where relevant, a limit (for example the number of digital twins or daily minutes).
- Every feature also has a global switch. When it is off, the feature shows as "coming soon" in every package. This is how unfinished features are held back at launch.
- Launch values are marked "(default)". Every change needs two-person approval and is written to the audit log.
- Changes apply to new jobs at once; jobs already confirmed finish under the settings shown at confirmation.

Details of the admin panel, roles and approval flow are in chapter 13.

## 6.6 Customer package comparison page

The public comparison page reads directly from the "Packages & features" page, so the website and the product never disagree.

- Each package shows its top 8 features first, with a "see all features" control that expands the full matrix.
- A short "which package is right for me?" helper asks three questions and recommends a package. The three questions and the answer-to-package mapping are set in the admin panel (wording to confirm).
- During the Free Beta the website shows the approved paid prices with the note "free during the Free Beta".
- Prices are shown in Taka in Bangladesh and in USD (later also EUR and GBP) abroad, as set out in chapter 7.

## Precedence

This blueprint is the single reference for Remon Motion Studio. Where it differs from the Master Blueprint v32.10, this document is newer and wins for Motion Studio; the differences are carried into the next Master Blueprint edition. Shared company matters — servers, security baseline, company accounting, legal entity — stay governed by the Master Blueprint and are summarised here only as far as Motion Studio needs them.

## Change rule

Every user-visible value in this blueprint (prices, limits, package features, thresholds, texts) is set in the admin panel, marked "(default)", changed only with two-person approval, and logged. A change to a value does not need a new edition of this document; a change to a rule or policy does.
